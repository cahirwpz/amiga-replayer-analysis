## Meaning of the columns

| Value  | Meaning                                                     |
| ------ | ----------------------------------------------------------- |
| hash   | A byte-identical binary sits next to the source.            |
| name   | Binary name matches a source file or directory.             |
| manual | Set by hand in `tools/inventory.py`.                        |
| none   | Searched by name and version string. Nothing found.         |
| uade   | Replay logic is in the UADE source.                         |
| module | Replay logic ships in the music file. UADE only patches it. |
| check  | Patch markers found. Read the source before relying on it.  |
| port   | A port outside UADE, under `ext/`.                          |

Several players share one source directory, for example the `MED` family.

## Sources from outside UADE

`AbyssHighestExperience` (AHX) has no source in UADE. The original 68000 source
was never published. `ext/ahx2play` is a C port of the same replayer, used as
`evidence: port`.

## Source without a player binary

Four source directories have no binary in `ext/uade/players`:

- `other/max_trax`
- `uade/ps3m`
- `wanted_team/Musicline4V`, `wanted_team/Musicline8V`

## Caveats

- Line counts include old versions kept next to new ones. Treat them as upper
  bounds.
- Three binaries have no version string: `EMS-6`, `Mark_Cooksey_Old`,
  `ScottJohnston`.
- `SynthPack` matched a directory that holds no source. It counts as binary
  only.
- Binary-only players can still be classified from docs and sibling players.

## Regenerate

Run `python3 tools/inventory.py --write` after moving a submodule pin. A
pre-commit hook runs `--check`.
